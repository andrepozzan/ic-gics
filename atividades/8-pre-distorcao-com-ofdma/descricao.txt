Implementei a seguinte sequência:

Bits -> OFDMA+QAM -> DPD -> PA -> Modulação para real + imag -> Demodulação -> Bits

Para a DPD utilizei a seguinte expressão: dpd_coef = dpdTraining(in_training, out_training),
em que essa função faz o calculo dos coeficientes invertendo a saída com a entrada para o mesmo
método feito anteriormente, o resultado no gráfico AM-AM foi bom.

Na demodulação foi necessário o ajuste de ganho:

Para potência média em duas dimensões I + Q do QAM:

ideal_symbol_power = (2.0 / 3.0) * (n_levels**2 - 1)

measured_power = np.mean(np.abs(symbols) ** 2)

if measured_power > 0:

gain = np.sqrt(ideal_symbol_power / measured_power)
symbols = symbols * gain
print('symbols: ', symbols)

Com esse ajuste pelo ganho a demodulação melhorou de forma significativa, observei que para poucos usuários
o ajuste necessário é baixo ~0,3 mas quanto aumento a quantidade para em torno de 20 passa para ~1,7, isso
é esperado pois a OFDMA exige bastante do amplificador em uma faixa grande de frequência e nem todas as faixas
possuem um bom treinamento dos coeficientes por conta dos dados de entrada.

Para o mapeamento do QAM segui o digrama de constelação de um slide do professor Marlio, utilizei os seguintes
espaçamentos qam_levels: [-3 -1 1 3] para a representação complexa, ex:
0000 -> -3 + j3

0001 -> -3 + j1

0011 -> -3 - j1

Pelo que pesquisei utilizar intervalos simétricos fica melhor para a detecção

Para simular a transmissão apliquei uma frequência de 50MHz
